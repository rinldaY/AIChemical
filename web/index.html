🧬 สถาปัตยกรรมโมเดลนำเสนอ: T²-LSTM (Proposed Hybrid Architecture)

โมเดล T²-LSTM ได้รับการออกแบบเพื่อแก้โจทย์เฉพาะของโรงงานเคมี โดยผสานขีดความสามารถในการสกัดพลวัตเวลาที่ไม่เป็นเส้นตรง (Non-linear Temporal Dynamics) ของ LSTM เข้ากับการควบคุมกระบวนการเชิงสถิติ (MSPC) ของ Hotelling's T² ในมิติเวกเตอร์แฝง (Latent Space)

Input Sequence Window (T=20, D=52)
Reset ทุก simulationRun
➔
Stacked LSTM Encoder 2 Layers (Hidden 64)
Extract Latent vector z (dim 24)
➔
Latent Hotelling's T² T²(z) = (z - μ)ᵀ Σ⁻¹ (z - μ)
ขอบเขต F-Distribution
➔
Composite Score γ(T²/T²_lim) + (1-γ)(SPE/SPE_lim)
Flag เมื่อ Score > 1.0

1. Hotelling's T² ใน Latent Space:

คำนวณเวกเตอร์ค่าเฉลี่ย $\mu_z$ และ Covariance matrix $\Sigma_z$ จากชุดข้อมูลปกติ 100%:

T²(z) = (z - μ_z)ᵀ · (Σ_z + εI)⁻¹ · (z - μ_z)

ควบคุมการเกิด False Alarm ด้วยขอบเขตทางสถิติระดับนัยสำคัญ α = 0.05

2. Squared Prediction Error (SPE):

LSTM Decoder ทำการสร้างสัญญาณทั้งหน้าต่างเวลากลับคืนมา:

SPE(X) = (1 / T·D) ∑ ∑ (X_{t,j} - X̂_{t,j})²

วัดความคลาดเคลื่อนในการสร้างสัญญาณเดิมของกระบวนการที่ไม่เป็นไปตามปกติ

🏭 โครงสร้างโรงงานจำลอง Tennessee Eastman Process (TEP)

กระบวนการ Tennessee Eastman Process ประกอบด้วย 5 หน่วยปฏิบัติการหลัก ได้แก่ เตาปฏิกรณ์เคมีแบบกวนต่อเนื่อง (Reactor), หม้อควบแน่น (Condenser), ถังแยกไอ-ของเหลว (Flash Drum Separator), คอมเพรสเซอร์หมุนเวียนก๊าซ (Compressor), และหอกลั่นไล่สารเบา (Stripper Column) รวมตัวแปรที่ตรวจวัดทั้งสิ้น 52 ตัวแปร

XMEAS 1 - 41 (Measurements)
อัตราการไหลของสารป้อน A, D, E, อุณหภูมิเตาปฏิกรณ์, ความดันในเตาปฏิกรณ์, ระดับของเหลวในถังแยกสาร, และองค์ประกอบก๊าซ
XMV 1 - 11 (Manipulated Variables)
วาล์วควบคุมการป้อนสาร D, E, A, อัตราการไหลของน้ำหล่อเย็นเตาปฏิกรณ์ (XMV 10), วาล์วระบายก๊าซส่วนเกิน (Purge Valve)
Faults 1 - 20 (Simulated Disturbance)
ความผิดปกติที่พบบ่อยในอุตสาหกรรม: การเปลี่ยนแปลงขั้นบันได (Step Change), การสะสมคราบในเครื่องแลกเปลี่ยนความร้อน (Drift), และวาล์วติดขัด
